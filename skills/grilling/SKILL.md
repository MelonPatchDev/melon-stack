---
name: grilling
description: Grill the user about a plan or design, one question at a time. Use when the user wants to stress-test a plan with them in the loop, or uses a 'grill' trigger phrase. To design without the user in the loop, use melon-concept in autonomous mode.
---

Interview the user about the plan until you share an understanding. Walk the design tree branch by branch, resolving dependencies in order. Ask one question at a time, with your recommended answer, and wait for theirs. Look facts up in the code instead of asking; put decisions to the user. Don't start building until they confirm.
