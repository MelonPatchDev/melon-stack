# Feature

**One whole user-visible slice, built to the test plan.**

- **One issue = one complete PR:** data, API, contract and UI together. Never split by layer.
- **A shared contract** someone else holds as a hotspot is a checkpoint; stop there.
- **UI:** the repo's design doc and tokens decide colours and sizes. Assert behaviour on seed data (text, roles, counts, URLs), not pixels. If you have them, use the `frontend-design` plugin for a new screen, and a data-visualization skill for charts.
- **Impact:** what each persona sees differently, including anything slower or more cluttered, compared with the issue's UX effect line.
